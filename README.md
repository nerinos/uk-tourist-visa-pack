# UK Tourist Visa Pack

Скилл для Codex: подготовка документов на туристическую **UK Standard Visitor** по [публичному гайду для подачи в Белграде](https://purple-buffer-e2b.notion.site/UK-Visa-265fa66f7cd6804a9eb2dd7493c2ee34).

## Что делает

- Проверяет комплектность документов по гайду и применимым обстоятельствам заявителя.
- Сверяет анкеты, доходы, даты, финансирование и письма между собой.
- Готовит английские переводы после оригиналов, cover letter и sponsor letter.
- Размещает PDF в 10 категориях VFS, отмечает недостающие документы и подписи.
- Проверяет размер каждого PDF строго менее 5 000 000 байт и собирает ZIP отдельно для каждого заявителя.

Скилл учитывает различия между рекомендациями неофициального гайда и актуальными требованиями UKVI. Он готовит локальный комплект; отправка заявок и загрузка документов требуют отдельного поручения. Техническая проверка PDF не является оценкой достаточности доказательств или гарантией выдачи визы.

## Установка в Codex

Скопируйте репозиторий в отдельную папку навыка:

```sh
git clone https://github.com/nerinos/uk-tourist-visa-pack.git "$HOME/.codex/skills/uk-tourist-visa-pack"
```

Если каталог уже существует, сначала сохраните свои изменения и выберите способ обновления; не заменяйте его вслепую.

Пример запроса:

> Используй $uk-tourist-visa-pack: проверь документы в указанной папке по гайду, подготовь переводы и письма, разложи PDF по разделам VFS и собери ZIP для каждого заявителя.

Передайте агенту путь к исходным документам и имеющиеся решения по конкретной заявке. [SKILL.md](SKILL.md) содержит рабочий процесс, [references/guide-checklist.md](references/guide-checklist.md) — чеклист и распределение по категориям.

## Локальный помощник

`scripts/pack_tools.py` выполняет инвентаризацию, проверку PDF и упаковку по manifest. Для него нужны Python 3.11+ и `pypdf`. Если подходящее окружение уже доступно в Codex, можно использовать его. Для отдельного окружения из каталога репозитория:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/pack_tools.py --help
```

Команды и формат manifest описаны в [references/pack-tools.md](references/pack-tools.md). Помощник не переводит и не сжимает PDF сам: эти операции выполняет агент доступными инструментами с последующей проверкой читаемости.

## Работа с документами

Храните исходники, готовые комплекты и рабочие результаты **вне этого репозитория**. Инвентаризация и manifest могут содержать имена файлов, абсолютные пути и сведения о заявителях. Не включайте их в коммиты. `.gitignore` исключает распространённые форматы документов и выходных файлов, но не заменяет проверку перед публикацией.

В репозиторий входят инструкции, общий код и условные примеры. Реальные анкеты, паспорта, переводы, письма и комплекты заявителей для работы скилла не поставляются.
